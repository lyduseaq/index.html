DIP Switch Calculator - PWA
1. Giải nén ZIP.
2. Tải toàn bộ nội dung bên trong thư mục này lên thư mục gốc (root) repository GitHub Pages.
3. Đảm bảo index.html, manifest.json, sw.js nằm cùng cấp; thư mục icons chứa icon-192.png và icon-512.png.
4. Commit changes, đợi GitHub Pages cập nhật.
5. Mở https://lyduseaq.github.io/index.html/ bằng Chrome/Edge hoặc Safari rồi cài ứng dụng.
